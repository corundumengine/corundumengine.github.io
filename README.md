# corundumengine.github.io

Website for the Corundum Engine.

## Fonts

Self-hosted in `assets/fonts/` (converted to WOFF2, only the weights actually
used in `style.css`):

- [Cormorant SC](https://fonts.google.com/specimen/Cormorant+SC) — display headings
- [Marcellus](https://fonts.google.com/specimen/Marcellus) — body copy and UI text
- [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) — code, dates, badges

All three are from Google Fonts under the SIL Open Font License 1.1; see
`assets/fonts/licenses/`.
