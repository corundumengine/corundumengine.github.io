The Project

Built for the love of CRPGs

I've been playing games for a long time, starting with Bard's Tale and Ultima III on an Apple IIe, and I'm still playing today. I have ideas about what I like in a role-playing game, and I want to build my own, but not on someone else's engine. That's how Corundum started. I'm building it on macOS, but it will eventually run on Windows and Linux too.
